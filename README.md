# dangal 🇮🇶
منصة رصد المنافسين — فيسبوك + انستاجرام

## الرفع على Vercel (خطوة بخطوة)

### الطريقة ١: بدون كود (الأسهل)
1. افتح https://github.com وسجّل حساب
2. اضغط New Repository → اسمه: dangal → Create
3. ارفع جميع الملفات بالسحب والإفلات
4. افتح https://vercel.com → سجّل بحساب GitHub
5. اضغط "Add New Project" → اختر dangal
6. اضغط Deploy ✅

### الطريقة ٢: بالكود (أسرع)
```bash
npm install
npm run dev        # تشغيل محلي على localhost:5173
npm run build      # بناء للإنتاج
npx vercel         # رفع مباشر على Vercel
```
